# Changelog

## 0.2.0 (2026-10-27)

Readings corrected against the stock install (every TOC, bundle manifest, EBX payload, depot and texture header of build 20260929 read). Breaking.

- **EBX 64-bit integers: `FieldType::Int64` is code 0x11 and `FieldType::UInt64` code 0x12** (they were the other way round). The game's own field names decide it (`CompareInt64EntityData.A` is code 0x11, `CompareUint64EntityData.A` code 0x12; none of 291 fields named for their signedness disagrees). Values of the 65 fields of code 0x12 now read as `Value::UInt` (17,750 of 77,112 have the top bit set and used to read negative) and the 12 fields of code 0x11 as `Value::Int`; written bytes do not change.
- **`TypeRef` names a slot of the EFIX type list, not an entry of the reflection table.** `TypeRef::descriptor` is replaced by `TypeRef::fixup_type` (the slot, `encoded >> 2`); `Document::type_ref_target` and `Document::fixup_type_target` find the reflected type of a slot by GUID and signature (`None` for the 499,474 of 513,119 stock references whose type the document does not reflect). Read as a reflection index (the old reading) 511,607 of 512,711 stock references named another type or none. `TypeRef::with_fixup_type` re-points a reference. `Carrier` now moves a type reference to the slot of the same type in the target's EFIX list, adding the type there if it has none, and no longer needs the target to reflect it; the writer refuses a reference past the list.
- **EBX floats keep their bits.** The writer wrote nothing for a NaN or an infinity (213 stock documents, 1,784 NaNs and one infinity, were refused); both are now read and written as stored, a NaN's payload and sign included. Every one of the 328,015 stock payloads is written again without a refusal and reads back to the same values (floats compared by bits). A finite value an `f32` field cannot hold is still refused.
- `depot::params` reads parameter type `0x566e2dd0` (one byte an element): the 732 stock material entries (95 blocks) it refused now parse; all 64,105 blocks of the 2,473 depots parse to their last byte.
- `cas::blocks` refuses a block whose flags nibble (the high four bits of header byte 5) is not 7. It is 7 in all 1,001,300 stock block headers and in all 1,535,187 blocks of the 82 mod folders installed beside them (ReSkate Studio maps among them); the writer already emitted `0x70`.
- `bundle::Asset::size` of a chunk is its `lsize`, the decoded size of the stored range, not `(loff & 0xFFFF) | lsize` (equal on every stock row, 239,810); `Asset::chunk_size()` is `loff + lsize`, the whole chunk (equal to the TOC chunk table's decoded size on all 40,504 stock rows with a nonzero `loff`).
- `texture::TextureHeader` names its fields: `unknown_00` is `mip_block_offsets: [u32; 2]` (the physical offsets of the 64 KiB blocks holding mips 1 and 2: right in all 39,632 stock headers whose chunk is in its TOC and where they are not both zero), `unknown_10` is `pool_id` (0 in every texture), `unknown_78` is `name_hash` (the djb2-xor of the lowercase resource name, all 61,618 stock texture headers), `unknown_7c` and `unknown_80`; `texture::flags` names the bits stock textures set. Bytes read and written are the same.
